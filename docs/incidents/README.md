# Incidents

One file per incident, newest first, named `YYYY-MM-DD-short-title.md`. Copy `TEMPLATE.md`.

An incident is anything that paged you, anything that cost more than one epoch of attestations,
and anything you did by hand that you would not want to do by hand again.
